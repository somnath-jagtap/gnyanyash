# Gnyanyash Website

Static landing website for the Gnyanyash Library Management Software product.

Before publishing:
1. Replace the placeholder contact details in privacy.html and terms.html.
2. Review the legal text for your actual business and jurisdiction.
3. Deploy the site to a public HTTPS URL.
4. Use that real URL in Meta's business information form.

Files:
- index.html — landing page
- privacy.html — privacy policy
- terms.html — terms of service
- styles.css — responsive styling
